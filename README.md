# Convert-image-to-e-paper
Convert your image into a form that can be recognized by e-paper.
Currently, only images in the .png format can be converted. Place your image in the same folder as epd_convert.py, and rename your image to "your_image". After running the code, there will be image information that the e-paper can understand in the epd_image.h file. If your file is in the .jpg format, you just need to replace all the .png files within the file with .jpg files, and it will work properly.
